# 🍺 Moe's Tavern Brazil

A simple front-end project inspired by **Moe's Tavern** from *The Simpsons*, developed to practice the fundamentals of web development using the front-end basic background: **HTML5**, **CSS3**, and **JavaScript**.

## 📖 About

This project was created as a learning exercise to strengthen front-end development fundamentals and improve practical experience with web technologies.

(Project developed as part of the Codifica/+PraTI - Full Stack Developer 2026 Course)

---

## 🎯 Objectives

- Practice semantic HTML
- Improve CSS layout techniques
- Build responsive interfaces
- Manipulate the DOM with JavaScript
- Learn Git and GitHub workflows
- Implement API concepts and usage

## 🚀 Features Practiced

- ✅ Semantic HTML5
- ✅ Flexbox
- ✅ CSS Grid
- ✅ Relative Units (`%`, `rem/em`, `vw/vh`)
- ✅ Media Queries
- ✅ CSS Imports
- ✅ Git & GitHub Workflow
- ✅ DOM Manipulation
- ✅ Query Selectors

- ✅ JavaScript Logic
